# Dog Schedule App: Product Brief

Shared context for all agents (designer, engineer, marketer, business, qa).
Update this file when the product direction changes.

## The idea
A daily schedule for a dog that a whole household shares. Family members
book (claim) and complete the dog's specific needs every day, so everyone
knows what's done and what's still open.

## Target users
A family/household sharing one dog.

## Core jobs to be done
- See today's dog tasks and who's on each one.
- Claim a task ("I'll take the evening walk").
- Mark a task done so nobody repeats it (e.g. double feeding).
- Get reminded before a task is due or when it's missed.
- Set up recurring tasks: walks, meals, medication, grooming, vet visits.

## MVP (draft, to be confirmed)
- Household with invited members
- One dog profile
- Recurring task templates
- Today view: claim / complete
- Push reminders
- Simple history
