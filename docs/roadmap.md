# Roadmap

Owner: business agent · Last updated: 2026-10-12 · Details: `docs/business/mvp-scope.md`, `docs/business/pricing.md`

Phases are gated by **metrics, not dates**. Indicative timing assumes a small team.

## Phase 0: Already built ✅
- Email/password accounts; one household per user; invite codes
- Daily needs (type, duration, repeat days)
- Today screen: shared book/complete with Realtime
- Member assignment & booking preferences
- Weekly repeating bookings + week navigation

## MVP: Greece + Cyprus soft launch (target: ~6 weeks out, all free)
- **Push reminders** (before due + missed-task nudge), server-scheduled
- **Simple history** (last 7 days)
- **Minimal dog profile** (name, photo, birthday); `dogs` table designed multi-dog-ready
- Invite **link** via share sheet (deep link join)
- Onboarding templates (Puppy / Adult / Senior-on-meds)
- Sign in with Apple; in-app account deletion; privacy policy; EU-hosted data
- Greek + English localisation
- Privacy-friendly analytics for activation / WAH / completion rate
- Exit gate: activation ≥ 40%, W4 retention ≥ 35%, ≥ 2 members active per household

## v1.1: Monetise + expand (≈ 2–3 months after MVP)
- **Premium (per household)**: €2.99/mo · €19.99/yr · optional €49.99 lifetime; founder offer for MVP households
- **Multiple dogs** (Premium, up to 5)
- Unlimited history + monthly recap (Premium)
- Missed-task escalation, quiet hours, per-member reminder settings
- Dog profile extras: vet contact, meds list, vaccination dates
- Task notes (e.g. "gave half pill")
- Home-screen widget (today's open tasks)
- Expand store availability: EU + UK + US; add DE/IT/ES localisation
- Test reverse trial vs. 7-day annual trial
- Exit gate: Premium conversion ≥ 3% of WAH; churn < 6%/mo on monthly

## v2: Grow the "pack" (≈ 6+ months)
- **Guest access** for sitters / walkers / grandparents (time-limited, Premium)
- Multiple households per user (two-home families, dog-sitters)
- Managed kid members (no email; parent-controlled)
- Lightweight health log: weight, food amount, symptoms; export PDF for vet
- Calendar sync (Google/Apple) for vet & grooming appointments
- Apple Watch / Wear OS quick-complete; web companion
- Gamification lite: family streaks, weekly "top helper"
- Explore partnerships (vets, groomers, pet shops in GR) for referral revenue
- Evaluate other pets (cats) only if data shows demand

## Not planned
- Walk GPS tracking, training content, in-app chat, ads
